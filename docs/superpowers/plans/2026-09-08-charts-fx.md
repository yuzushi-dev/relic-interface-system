# RIS Charts FX & Tactical Scrubber Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform static RIS charts into tactical, cybernetic telemetry tools with interactive Kiroshi HUD scrubbers and subtle ambient micro-sweeps, using exclusively 100% real data.

**Architecture:** Zero-reflow SVG overlay architecture (`<g class="ris-chart-scrubber">` pre-rendered inside viewBox) updated via standard Pointer and Keyboard events, combined with hardware-accelerated CSS keyframe animations in `ris-fx.css` for ambient micro-sweeps and peak warning pulses.

**Tech Stack:** Vanilla JavaScript (ES6+), SVG 2.0, CSS Keyframes & Custom Properties, Playwright / Headless Firefox for automated visual verification.

## Global Constraints

- **Strict Real Data:** No fake metrics, simulated hashes, dummy timestamps, or decorative placeholder lore. Every displayed value maps directly to dataset points (`v`, `t`, computed deltas, real units).
- **Zero Reflow:** No DOM elements created or destroyed on mouse/touch moves. Use SVG attribute mutations on pre-created elements.
- **Accessibility:** Charts must be keyboard navigable (`tabindex="0"`, `ArrowLeft`/`ArrowRight`), support ARIA live/value attributes, and provide high contrast (>= 4.5:1).
- **Reduced Motion:** When `prefers-reduced-motion: reduce` is active, all ambient sweeps, breathing, and pulses must immediately cease. Scrubber remains operational with instant snap.
- **Commands:** Shell commands must be prefixed with `rtk` (never `rtk find` or `rtk pytest --collect-only`).
