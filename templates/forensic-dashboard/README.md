## ◈ Overview & Architecture

The **Forensic Telemetry Dashboard** is a turnkey Next.js 14 App Router application engineered for defense contractors, hardware diagnostics, cybersecurity operations centers, aerospace telemetry, and biometric medical monitors.

Unlike generic SaaS dashboard templates, it avoids fake random numbers and decorative CSS lag. Every telemetry panel, event log buffer, and SVG chart binds to real data streams with hardware-accelerated 60fps performance and zero layout shift.

### What's Included in the Pro Package:
1. **Next.js 14 App Router Architecture**:
   - Clean modular layout (`app/layout.tsx`, `app/page.tsx`, `app/globals.css`).
   - Dogfoods `@relic-ui/react` and `@relic-ui/tailwind` preset.
   - 100% strict TypeScript types with zero `any` shortcuts.
2. **Tactical Component Suite**:
   - `TopBar.tsx`: HUD status chrome with live lock indicator, UTC ticker, theme toggle (Dark / Light), and 4-brand switcher (`relic`, `biohub`, `omnikon`, `neutral`).
   - `Sidebar.tsx`: Tactical collapsible navigation rail with segmented memory meters and clearance indicator.
   - `KpiGrid.tsx`: 4 high-contrast telemetry KPI stat cards with trend badges and delta values.
   - `TelemetryScrubber.tsx`: Interactive SVG line chart with real-time mouse/touch scrubbing, threshold alerts (`[PEAK ALERT]`), and delta badges (`Δ +18`).
   - `EventLogStream.tsx`: Live forensic circular buffer stream with severity filters (`INFO`, `WARN`, `CRITICAL`), pause/resume stream toggle, and buffer clear.
   - `SystemModal.tsx`: Tactical override confirmation modal with focus trap, ESC listener, and 240ms enter animation.
   - `MobileBottomSheet.tsx`: Touch bottom sheet for viewports <768px with drag gesture handle and OLED safety.
3. **Production Deployment Ready**:
   - Multi-stage standalone `Dockerfile` for Docker and Kubernetes.
   - Pre-configured PostCSS and Tailwind CSS preset.
   - Self-contained offline dependencies (compiled `@relic-ui/react` and `@relic-ui/tailwind` packages vendored).
