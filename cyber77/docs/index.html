Relic Interface System

Linguaggio visivo cyberpunk/HUD: superfici graphite, bordi 1px duri, angoli clippati, accenti neon disciplinati (palette Cyberpunk 2077), texture grid + scanline, motion meccanico 90–160ms. Dark e light, desktop e mobile, multi-brand. Lo stato non è mai solo colore: sempre etichetta o icona. Conformità WCAG 2.2 AA: contrasti verificati, focus visibile, prefers-reduced-motion, target ≥24px.
